# Sprint_6

Учебные UI-автотесты сервиса «Яндекс.Самокат».

Сайт: https://qa-scooter.education-services.ru/

## Технологии

Python, Selenium, pytest, Allure.
Браузер для запуска тестов — Mozilla Firefox.
Проект организован с использованием Page Object Model.

## Проверки

- Раскрытие восьми вопросов в разделе «Вопросы о важном» и проверка соответствующих ответов.
- Оформление заказа с двумя наборами данных: через верхнюю и нижнюю кнопки «Заказать».
- Переход на главную страницу по логотипу «Самоката».
- Открытие новой вкладки по логотипу Яндекса и проверка перехода на Дзен согласно заданию.

Всего 12 тестовых случаев.
Для вопросов и оформления заказа используется параметризация.

## Структура проекта

- pages — классы страниц и общей шапки.
- locators — локаторы элементов.
- test — тесты вопросов, заказа и навигации.
- data.py — адреса, тестовые данные и ожидаемые результаты.
- requirements.txt — зависимости Python.
- allure_results — результаты запусков для Allure.

## Подготовка окружения

Необходимо установить Python и Mozilla Firefox.
Для просмотра отчёта нужны Allure CLI и Java.

Команды для Windows PowerShell из корня проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Перед запуском проверьте даты доставки в data.py:
они должны быть будущими.

## Запуск тестов

```powershell
.\.venv\Scripts\python.exe -m pytest test -v
```

## Результаты и отчёт Allure

Запуск с записью результатов:

```powershell
.\.venv\Scripts\python.exe -m pytest test -v --alluredir=allure_results
```

Просмотр отчёта:

```powershell
allure serve allure_results
```
